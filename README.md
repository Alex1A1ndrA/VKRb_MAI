# Автоматизированная система генерации протоколов защит и предзащит ВКР

Веб-приложение для автоматического формирования протоколов государственной итоговой аттестации (защит и предзащит выпускных квалификационных работ) на основе загружаемых пользователем данных. Система предназначена для сотрудников кафедр, отвечающих за организацию ГИА, и позволяет существенно сократить время на подготовку документов, исключив ручной ввод и ошибки.

## Актуальность

Процедура заполнения протоколов защит и предзащит ВКР вручную требует значительных временных затрат и подвержена ошибкам. Ежегодный рост числа студентов увеличивает нагрузку на сотрудников кафедр, что делает автоматизацию данного процесса критически важной. Разработанное приложение позволяет:

- централизованно хранить данные о студентах, комиссиях, датах защит/предзащит;
- автоматически подставлять данные в шаблоны протоколов;
- генерировать готовые документы в формате `.docx` с соблюдением всех требований оформления;
- исключить дублирование работы и минимизировать человеческий фактор.

## Цель

Разработать веб-приложение для автоматизированного формирования протоколов защит и предзащит ВКР на основе загружаемых пользователем данных.

## Функциональные возможности

- **Генерация протоколов защит**  
  На основе данных о студентах, составе ГЭК, расписании защит и оценках формируются индивидуальные протоколы для каждого студента. Поддерживаются шаблоны с 4 и 5 членами комиссии.

- **Генерация протоколов предзащит**  
  Автоматическое создание протоколов предзащит для бакалавров и магистров с учётом присутствия студентов, замечаний по темам и руководителям, а также формирование списка неявившихся.

- **Генерация итоговых протоколов комиссии**  
  Формирование сводных протоколов комиссии по датам защит или предзащит (с горизонтальной ориентацией страницы).

- **Гибкий выбор дат**  
  Пользователь может выбирать конкретные даты и группы для генерации через интерактивную таблицу в интерфейсе.

- **Поддержка разнообразных входных данных**  
  Система загружает данные из Excel-файлов:
  - `Студенты.xlsx` – список студентов, темы, руководители, оценки и др.
  - `Даты.xlsx` – расписание защит и предзащит.
  - `Комиссия.xlsx` – состав комиссий для предзащит.
  - `Программы.xlsx` – справочник образовательных программ.
  - `Состав ГЭК.docx` – состав ГЭК для защит.

- **Склонение ФИО**  
  Автоматическое склонение фамилий, имён и отчеств в нужные падежи (родительный, дательный, творительный) с учётом пола и сложных окончаний.

- **Работа с вопросами**  
  Импорт вопросов из Excel и их привязка к членам комиссии.

## Используемые технологии

- **Python 3.10+**
- **Streamlit** – веб-интерфейс
- **pandas** – работа с табличными данными
- **python-docx** и **docxtpl** – генерация документов Word
- **pymorphy3** – морфологический анализ (склонение)
- **openpyxl** – чтение Excel-файлов

## Установка и запуск

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/Alex1A1ndrA/VKRb_MAI.git
   cd vkr-protocol-generator
   ```

2. **Создание и активация виртуального окружения**
   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/macOS
   venv\Scripts\activate      # Windows
   ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Подготовка данных**  
   Поместите необходимые файлы в папку `d:/Lab_Pyth/Предзащиты/ВКР/` (или измените `BASE_PATH` в `constants.py`). Структура файлов описана в разделе **Структура входных данных**.

5. **Запуск приложения**
   ```bash
   streamlit run app.py
   ```

6. **Открыть в браузере**  
   Перейдите по адресу `http://localhost:8501`.

## Структура входных данных

Все файлы должны быть расположены в папке, указанной в `BASE_PATH`. Пример структуры:

```
BASE_PATH/
│
├── Даты.xlsx               # листы: "Даты защит", "Даты предзащит"
├── Комиссия.xlsx           # лист "Лист1" с колонками: Фамилия, Имя, Отчество, Должность, Степень, Звание
├── Программы.xlsx          # лист "Лист1" с колонками: Код, Направление, Профиль, Квалификация, Уровень, Год_поступления, Группы
├── Студенты.xlsx           # лист "итог" (основные данные) и листы "защ", "пред" (вопросы)
├── Состав ГЭК.docx         # документ состава ГЭК для защит (парсится автоматически)
├── ЗащитыТаблицы5.docx     # шаблон протокола защиты с 5 членами комиссии
├── ЗащитыТаблицы4.docx     # шаблон протокола защиты с 4 членами комиссии
├── Предзащиты.docx         # шаблон протокола предзащиты для бакалавров
├── ПредзащитыМаг.docx      # шаблон протокола предзащиты для магистров
└── Протокол комиссии.docx  # шаблон итогового протокола комиссии
```

### Описание ключевых полей Excel

**Студенты.xlsx (лист "итог")**  
- `ФИО` – полное имя студента
- `Группа` – номер группы (например, 403)
- `Тема` – тема ВКР
- `Руководитель` – ФИО руководителя (с должностью)
- `Консультант`, `Рецензент` – аналогично
- `Присутствие_пред` / `Присутствие_защ` – отметка о явке или причина отсутствия (например, "Академ", "полное отсутствие")
- `Новая_тема`, `Новый_рук` – поля для исправлений после предзащиты
- `Оценка_защ` – числовая оценка (5,4,3)

**Даты.xlsx (лист "Даты защит")**  
- `Группа_полная` – полное название (например, "М8О-403Б-22")
- `Даты_основные` – даты через разделители (например, "14.06.25 / 15.06.25")
- `Время` – время начала (например, "10:00")
- `Председатель` – ФИО председателя комиссии

**Даты.xlsx (лист "Даты предзащит")**  
- `Группа_короткая` – номер группы
- `Дата_предзащиты` – строка вида "14.05.25-15.05.25<br>10:00" (даты и время)
- `Комиссия` – фамилии членов комиссии через `<br>` или запятые

## Использование

1. **Выбор типа документа**  
   В боковой панели выберите: `Защита`, `Предзащита` или `Протокол комиссии`.

2. **Выбор дат и групп**  
   Появится таблица со всеми доступными датами и группами. Отметьте нужные строки (или используйте кнопки «Выбрать все» / «Снять все»).

3. **Генерация**  
   Нажмите «🚀 Сгенерировать». Приложение обработает данные и создаст файлы в соответствующих выходных папках:
   - `DataZ/` – протоколы защит
   - `dataP/` – протоколы предзащит
   - `protocols/` – итоговые протоколы комиссии

4. **Результат**  
   Готовые документы можно открыть в Microsoft Word или любом совместимом редакторе. Все протоколы имеют корректное форматирование, поля, ориентацию страниц (горизонтальная для итоговых протоколов).
