# Автоматизированная система генерации протоколов защит и предзащит ВКР

Веб-приложение для автоматического формирования протоколов государственной итоговой аттестации (защит и предзащит выпускных квалификационных работ) на основе загружаемых пользователем данных. Система предназначена для сотрудников кафедр, отвечающих за организацию ГИА, и позволяет существенно сократить время на подготовку документов, исключив ручной ввод и ошибки.

## Актуальность

Процедура заполнения протоколов защит и предзащит ВКР вручную требует значительных временных затрат и подвержена ошибкам. Ежегодный рост числа студентов увеличивает нагрузку на сотрудников кафедр, что делает автоматизацию данного процесса критически важной. Разработанное приложение позволяет:

- централизованно хранить данные о студентах, комиссиях, датах защит/предзащит;
- автоматически подставлять данные в шаблоны протоколов;
- генерировать готовые документы в формате `.docx` с соблюдением всех требований оформления;
- исключить дублирование работы и минимизировать человеческий фактор.

## Цель

Разработать веб-приложение для автоматизированного формирования протоколов защит и предзащит ВКР на основе загружаемых пользователем данных.

## Функциональные возможности

### Основные разделы

- **Генерация протоколов защит**  
  На основе данных о студентах, составе ГЭК, расписании защит и оценках формируются индивидуальные протоколы для каждого студента. Поддерживаются шаблоны с 4 и 5 членами комиссии.

- **Генерация протоколов предзащит**  
  Автоматическое создание протоколов предзащит для бакалавров и магистров с учётом присутствия студентов, замечаний по темам и руководителям, а также формирование списка неявившихся.

- **Генерация итоговых протоколов комиссии**  
  Формирование сводных протоколов комиссии по датам защит или предзащит (с горизонтальной ориентацией страницы).

- **Загрузка и парсинг приказов**  
  Позволяет загрузить PDF-файлы проектов приказов о допуске к ВКР. После обработки автоматически создаются (или обновляются) файлы:
  - `Data/Студенты.xlsx` (листы: `итог`, `защ`, `пред`)
  - `Data/Программы.xlsx` (лист: `Лист1`)
  
  Это избавляет от необходимости вручную заполнять Excel-файлы.

- **Анализ ФИО**  
  Выявляет записи студентов, которые могут вызвать проблемы при склонении (не 3 части, неопределённый пол). Для каждой проблемной записи показывает список уже сгенерированных протоколов (защит, предзащит, протоколов комиссии) с возможностью скачать их для ручной доработки.

### Дополнительные возможности

- **Гибкая диагностика**  
  При выборе дат система проверяет наличие дат в файле `Даты.xlsx`, наличие председателя и состава ГЭК для защит, наличие комиссии для предзащит. Для групп, у которых не хватает данных, выводится подробное сообщение.

- **Нормализация названий групп**  
  Группы отображаются в едином формате `М8О-...Б-22` или `М8О-...СВ-24` независимо от исходного написания в загружаемых файлах.

- **Поддержка разнообразных входных данных**  
  Система загружает данные из Excel-файлов:
  - `Студенты.xlsx` – список студентов, темы, руководители, оценки, отметки о присутствии и т.д.
  - `Даты.xlsx` – расписание защит и предзащит (листы `Даты защит`, `Даты предзащит`). (на данный момента выпуск 26 года)
  - `Комиссия.xlsx` – состав комиссий для предзащит (лист `Лист1` с полями: Фамилия, Имя, Отчество, Должность, Степень, Звание).
  - `Программы.xlsx` – справочник образовательных программ.
  - `ГЭК_состав.docx` – состав ГЭК для защит (парсится автоматически). (на данный момента выпуск 26 года)

- **Склонение ФИО**  
  Автоматическое склонение фамилий, имён и отчеств в нужные падежи (родительный, дательный, творительный) с учётом пола и сложных окончаний.

- **Работа с вопросами**  
  Импорт вопросов из Excel (листы `защ` и `пред` в `Студенты.xlsx`) и их привязка к членам комиссии.

## Используемые технологии

- **Python 3.10+**
- **Streamlit** – веб-интерфейс
- **pandas** – работа с табличными данными
- **python-docx** и **docxtpl** – генерация документов Word
- **pdfplumber** – извлечение данных из PDF-файлов приказов
- **pymorphy3** – морфологический анализ (склонение)
- **openpyxl** – чтение и запись Excel-файлов

## Установка и запуск

1. **Клонирование репозитория**
   ```bash
   git clone https://github.com/Alex1A1ndrA/VKRb_MAI.git
   cd VKRb_MAI
   ```

2. **Создание и активация виртуального окружения**
   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/macOS
   venv\Scripts\activate      # Windows
   ```

3. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

4. **Подготовка данных**  
   Поместите необходимые файлы в папку `Data/` (или измените `BASE_PATH_DATA` в `constants.py`).  
   **Важно:** файлы `Даты.xlsx`, `Комиссия.xlsx`, `ГЭК_состав.docx` и шаблоны `.docx` должны присутствовать.  
   Файлы `Студенты.xlsx` и `Программы.xlsx` могут быть созданы автоматически через раздел «Загрузка приказов».

5. **Запуск приложения**
   ```bash
   streamlit run app.py
   ```

6. **Открыть в браузере**  
   Перейдите по адресу `http://localhost:8501`.

## Структура входных данных

```
Data/

├── Студенты.xlsx           # лист "итог" (основные данные) и листы "защ", "пред" (вопросы)
├── ГЭК_состав.docx         # документ состава ГЭК для защит (парсится автоматически)

Templates/
├── ЗащитыТаблицы5.docx     # шаблон протокола защиты с 5 членами комиссии
├── ЗащитыТаблицы4.docx     # шаблон протокола защиты с 4 членами комиссии
├── Предзащиты.docx         # шаблон протокола предзащиты для бакалавров
├── ПредзащитыМаг.docx      # шаблон протокола предзащиты для магистров
└── Протокол комиссии.docx  # шаблон итогового протокола комиссии
```

### Описание ключевых полей Excel

**Студенты.xlsx (лист "итог")**  
- `ФИО` – полное имя студента
- `Группа` – номер группы (например, `403Б` или полное `М8О-403Б-22`)
- `Тема` – тема ВКР
- `Руководитель` – ФИО руководителя (с должностью)
- `Консультант`, `Рецензент` – аналогично
- `Присутствие_пред` / `Присутствие_защ` – отметка о явке или причина отсутствия (например, "Академ", "полное отсутствие")
- `Новая_тема`, `Новый_рук` – поля для исправлений после предзащиты
- `Оценка_защ` – числовая оценка (5,4,3)

**Даты.xlsx (лист "Даты защит")**  
- `Группа` – короткое или полное название группы
- `Дата защиты` – даты через разделители (например, `03.06.26<br>10:00,<br>14:00`)
- `Председатель` – ФИО председателя комиссии
- `Аудитория` – необязательно

**Даты.xlsx (лист "Даты предзащит")**  
- `Группа` – короткое название группы (например, `401Б`)
- `Дата предзащиты` – строка вида `04.05.26-05.05.26<br>10:00`
- `Комиссия` – фамилии членов комиссии через `<br>` или запятые
- `Аудитория` – необязательно

**Комиссия.xlsx (лист "Лист1")**  
- `Фамилия`, `Имя`, `Отчество`, `Должность`, `Степень`, `Звание`

**Программы.xlsx (лист "Лист1")**  
- `Код`, `Направление`, `Профиль`, `Квалификация`, `Уровень`, `Год_поступления`, `Группы`

## Использование

1. **Загрузка приказов (рекомендуется первый шаг)**  
   - Перейдите в раздел «Загрузка приказов».
   - Загрузите один или несколько PDF-файлов приказов (проектов приказов о допуске к ВКР).
   - Нажмите «Обработать и сохранить в Data». Будут созданы файлы `Студенты.xlsx` и `Программы.xlsx`.
   - После этого можно перейти к другим разделам.

2. **Генерация протоколов**  
   - В боковой панели выберите нужный раздел: «Защита», «Предзащита» или «Протокол комиссии».
   - При необходимости отметьте нужные даты/группы в таблице (кнопки «Выбрать все» / «Снять все»).
   - Нажмите «Сгенерировать».
   - Готовые файлы появятся в папках `Results/DataZ/` (защиты), `Results/dataP/` (предзащиты), `Results/protocols/` (протоколы комиссии).

3. **Анализ ФИО**  
   - Раздел помогает выявить проблемные записи (не 3 части, неопределённый пол).
   - Для каждой проблемной записи показываются ранее сгенерированные протоколы, которые можно скачать и отредактировать вручную.

## Диагностика и сообщения

- Если для какой-либо группы не найдены даты в файле `Даты.xlsx` – система выведет список таких групп и предложит добавить строки.
- Если отсутствует председатель или состав ГЭК для защит – будет указано, каких данных не хватает.
- Если в листе `Даты предзащит` не указана комиссия или фамилии не найдены в файле `Комиссия.xlsx` – также выводится предупреждение.
- Все ошибки не блокируют работу с остальными группами – генерация продолжится для групп, у которых данные в порядке.
